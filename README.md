# 建筑材料 999（NeoForge 1.21.1）

让指定的一组建筑材料从原版 64 个一组改为 **999 个一组**。

## 已支持

- 石头、圆石、深板岩等石质建材
- 橡木及其他木材的原木、木板、楼梯、台阶、门、栅栏等
- 砖、砂岩、石英、陶瓦、玻璃、混凝土、铜块等常见建材
- 玩家背包、箱子、潜影盒、漏斗和 NeoForge 自动化物品处理器
- 999 个物品在玩家重新登录、重启服务器、存入箱子后正常保存

## 重要

1. 这是双端模组：**服务端和客户端都必须安装同一个 JAR**。
2. 文件建议命名为 `[建筑材料999] stack999-1.0.2.jar`。
3. 修改物品清单需要数据包，标签为 `stack999:stack_999`。
   - 模组自带清单：`src/main/resources/data/stack999/tags/item/stack_999.json`
   - 可用 `replace: true` 的同名数据包标签整体替换清单
   - 也可用 `replace: false` 继续追加物品或 `#命名空间:其他标签`

## 构建

```bash
cd /opt/Mc/stack999-mod
./gradlew clean build
```

构建结果：

```text
build/libs/stack999-1.0.2.jar
```

## 建议测试

1. 同时安装到服务端和客户端。
2. `/give 玩家名 minecraft:stone 999`
3. 把这组物品放进箱子、潜影盒，重新登录后确认仍是 999 个。
4. 把两组 999 个物品合并，确认每组上限保持 999。
